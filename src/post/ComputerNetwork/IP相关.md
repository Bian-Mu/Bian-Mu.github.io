
### IP分类

IP地址分为A-E共5类，32位地址划分为类号、网络号、主机号。主机号全0时表示某个网络，全1时表示网络下所有主机来实现广播

- Class A: 1.0.0.0 — 126.255.255.255，默认掩码 /8（注意 127.0.0.0/8 为回环）。
- Class B: 128.0.0.0 — 191.255.255.255，默认掩码 /16。
- Class C: 192.0.0.0 — 223.255.255.255，默认掩码 /24。
- Class D: 224.0.0.0 — 239.255.255.255（IP多播/组播）。
- Class E: 240.0.0.0 — 255.255.255.255（保留/实验）。

无分类地址CIDR去除了类号，表示为A.B.C.D/X，其中X表示前X位为网络号，其余为主机号

### IPv4与IPv6

IPv4：32位，点分十进制
IPv6：128位，冒号十六进制，设计目标是无需NAT，无广播
