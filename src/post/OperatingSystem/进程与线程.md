
### 进程

进程的三个状态：运行、就绪、阻塞，CPU会分割时间片来并发处理进程

被阻塞的进程通常会被换入到硬盘中

外存中的阻塞、就绪状态被称为挂起

#### 进程的控制结构

PCB进程控制块是进程存在的唯一标识

PCB通过链表组成各种状态的队列

1. 创建：父进程可以创建子进程并分配资源与PCB，而后进入合适的队列
2. 终止：分为正常结束、异常结束、信号kill
3. 阻塞：进程需要前置条件时会进入阻塞等待唤醒
4. 唤醒：其他进程唤醒当前进程

进程共享CPU资源，因此需要实现上下文切换：保存当前进程，加载下一进程

### 线程

线程是进程中独立的一部分，拥有自己的寄存器和栈。各个线程并发的执行，可以互相共享资源，因此这部分资源是不需要上下文切换的，开销更小

CPU调度本质上是对线程调度，进程只是提供了各种资源

TCB线程控制块分为用户、内核、轻量级三种

### 调度算法

非抢占式、抢占式（卡时间片）

#### 进程调度

1. 先来先服务FCFS
2. 最短作业优先SJF
3. 高响应比优先HRRM
4. 时间片轮转RR
5. 最高优先级HPF
6. 多级反馈MFQ

#### 页面置换（发生在缺页中断）

1. 最佳页面OPT
2. 先进先出FIFO
3. 最近最久未使用LRU
4. 时钟页面Lock
5. 最不常用LFU

#### 磁盘调度（操控磁头）

1. FCFS
2. 最短寻道时间优先SSF
3. 扫描Scan
4. 循环扫描CScan
5. LOOK与CLOOK（不完全的扫描）

### 进程间通信

1. 管道：单向、先进先出，效率低
2. 消息队列：链表，通信不及时且大小限制
3. 共享内存：多进程修改时冲突
4. 信号量：PV操作实现进程的互斥与同步
5. 信号：异常状态下的异步通信，对信号的处理方式分为执行默认操作、捕捉、忽略
6. Socket：实现跨网络的通信，也可以本地通信，使用两个Socket：监听、传送数据

### 多线程同步

线程间对于共享的资源，需要上锁/或者PV

操作共享变量的代码称为临界区，应该互斥访问，让信息实现同步

### 死锁

两个线程为了保护两个不同的共享资源使用的互斥锁

死锁发生的条件：

1. 互斥
2. 持有并等待
3. 不可剥夺
4. 环路等待

通常使资源分配有序来破坏死锁

锁有以下种类：

1. 乐观锁
2. 悲观锁
3. 互斥锁
4. 自旋锁
